EmpathyScale 演示版使用说明（老师）
================================

一、快速开始
------------
1) 双击运行 `EmpathyScale.exe`
2) 等待浏览器自动打开：
   `http://127.0.0.1:7860`
3) 在网页中直接输入场景描述并完成访谈
4) 点击“继续”后，系统会自动完成后续流程并生成结果页面

二、本版本说明
--------------
- 已内置当前演示所需配置，无需手动修改 API key 或模型设置
- 默认使用当前演示档位（保留完整流程，但运行时间更适合课堂展示）
- 默认模型为 `deepseek-v4-flash`

三、网络说明
------------
- 本程序运行时仍需要联网调用模型与公开文献检索接口
- 如果网络受限，请确保当前环境可以正常访问对应服务后再启动

四、首次运行可能稍慢
--------------------
- 首次运行时，浏览器启动和依赖加载可能会稍慢一些，属于正常现象

五、如果浏览器没有自动打开
--------------------------
请手动在浏览器地址栏输入：
`http://127.0.0.1:7860`

六、常见问题
------------
可同时参考同目录中的：
- `常见问题_含VPN提示.txt`
- `启动网页端.bat`
