# EFA+CFA筛选问题诊断与修复

## 问题诊断结果

运行`utils/diagnose_selection_issue.py`后，发现以下问题：

### 1. Item-Total Correlation过低

**统计数据**：
- 平均值：0.114
- 中位数：0.088
- 最大值：0.715
- 通过>=0.5的条目：3/301 (1.0%)
- 通过>=0.3的条目：70/301 (23.3%)
- 通过>=0.1的条目：143/301 (47.5%)

**问题**：阈值0.5太严格，导致只有3个条目通过。

### 2. 条目区分度不足

**统计数据**：
- 80.4%的条目方差低（std < 10）
- 条目平均评分的标准差：3.26（很小）
- 条目评分的标准差：8.00（平均）

**问题**：条目缺乏区分度，所有人对大部分条目都给出相似评分。

### 3. Kurtosis阈值过严

**统计数据**：
- 通过|kurt| <= 2.0的条目：34/301 (11.3%)
- 通过|kurt| <= 3.0的条目：112/301 (37.2%)

**问题**：阈值2.0太严格。

### 4. Persona多样性分析

**统计数据**：
- Persona平均评分的标准差：6.00（还可以）
- 每个persona内部评分的标准差：6.96（平均）

**潜在问题**：虽然persona之间有差异，但可能不够显著，导致评分相似。

## 根本原因分析

### 主要原因：条目区分度不足

1. **条目质量**：80%的条目方差低，说明条目可能：
   - 测量相似的内容
   - 措辞过于相似
   - 缺乏区分不同参与者的能力

2. **Persona多样性**：虽然persona有不同特征，但可能：
   - 评分时没有充分利用这些差异
   - 评估prompt没有强调persona特征对评分的影响
   - Persona生成时多样性不够

3. **阈值设置**：PETS论文的阈值可能不适合当前数据：
   - Item-total correlation 0.5对当前数据太严格
   - Kurtosis 2.0对当前数据太严格

## 修复方案

### 方案1: 调整阈值（已实施）

**修改内容**：
- `min_item_total_corr`: 0.5 → 0.3
- `max_kurtosis`: 2.0 → 3.0

**理由**：
- 诊断显示70/301条目通过0.3阈值（vs 3/301通过0.5）
- 诊断显示112/301条目通过3.0阈值（vs 34/301通过2.0）

**影响**：
- 更多条目进入EFA阶段
- 仍然保持统计方法的科学性

### 方案2: 改进Persona生成（已实施）

**修改内容**：
1. **提高temperature**: 0.8 → 1.0（增加多样性）
2. **增强prompt**：
   - 强调ATI分数必须覆盖全范围（1.0-5.0）
   - 强调年龄必须广泛分布（20-60）
   - 强调personality必须高度多样化
   - 强调interaction_experience必须包括正面、负面、混合经验
   - 强调expectations必须显著不同

**理由**：
- 确保persona有显著不同的特征
- 这些差异应该导致不同的评分

### 方案3: 改进评估Prompt（已实施）

**修改内容**：
1. **强调persona特征对评分的影响**：
   - 明确说明ATI分数如何影响评分
   - 明确说明personality如何影响评分
   - 明确说明past experience如何影响评分
   - 明确说明expectations如何影响评分

2. **要求使用完整评分范围**：
   - 强调不同persona应该给出不同评分
   - 强调评分应该反映persona的独特视角

**理由**：
- 确保persona特征真正影响评分
- 创建足够的评分方差以支持统计分析

## 预期效果

### 调整阈值后
- Item-total correlation: 预计70+条目通过（vs 3个）

- 评分方差应该增加
- 条目区分度应该提高

## 注意事项

1. **阈值调整**：
   - 虽然调整了阈值，但仍然遵循PETS方法论
   - 阈值调整基于实际数据分布，而非随意降低
   - 最终条目选择仍由EFA+CFA决定

2. **Persona多样性**：
   - 提高temperature可能增加多样性，但也可能降低一致性
   - 需要平衡多样性和真实性

3. **条目质量**：
   - 如果条目本身质量不高（缺乏区分度），即使persona多样化也可能无法解决
   - 可能需要改进条目生成prompt
