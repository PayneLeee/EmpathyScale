# English Presentation Materials

This folder contains the English version of the presentation materials for the EmpathyScale project.

## Files

- `presentation_slides.md` - English translation of the presentation slides
- `visualizations/` - All visualization images referenced in the slides

## Usage

The English presentation slides can be used for:
- International conferences and presentations
- English-speaking audiences
- Academic submissions requiring English materials

## Image References

All images in the `visualizations/` folder are referenced with relative paths in `presentation_slides.md`. The images include:
- System architecture diagram
- Workflow diagram
- Evaluation metrics explanation
- Scenario comparison
- Experiment results
- Ablation study results
- Baseline comparison
- Dimension examples
- And more...

## Notes

- The original Chinese version remains in the parent `presentation/` directory
- All images are identical to those used in the Chinese version
- The content structure and slide organization match the Chinese version
